## Setup

1. `pip install -r requirements.txt`
2. Add API keys in `.env`
3. `python setup_db.py`
4. `cd flask_api && python train_model.py`
5. Terminal 1: `cd flask_api && python app.py` (port 5001)
6. Terminal 2: `python app.py` (port 5000)
7. Open: `http://127.0.0.1:5000`
8. Add `hero_bg.png` to `static/assets/`
