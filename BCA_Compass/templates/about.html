🧭 About BCA-AI Compass

Built by students, for students — A legacy for future BCA-AI batches

🎯 What is BCA-AI Compass?

BCA-AI Compass is an AI-powered web platform built specifically for BCA-AI (Artificial Intelligence and Data Analytics) students at Narmad College of Science and Commerce, Bharuch.

As the first batch of this newly introduced program, we faced challenges due to absence of senior guidance, organized study resources, and exam preparation material. This project solves all these problems in one platform.

💡 Why Was This Built?

BCA-AI is a new program at Narmad College. Our batch was the first to study it — we had no senior students, no organized resources, no one to guide us.

BCA-AI Compass is the senior we never had. Built so no future student faces what we faced — a permanent resource that grows with every passing batch. 🎓

🚀 Platform Modules

6 AI-powered modules for complete student guidance

📚

Resource Hub

Subject-wise study notes with smart topic suggestions using Apriori Algorithm. Admin uploads materials, students access anytime.

📝

Exam Compass

Access past exam papers and generate AI-powered practice papers based on uploaded study materials and past paper patterns.

🎯

Career Predictor

ML-powered career path predictor using K-Means Clustering and Apriori Algorithm. Predicts primary and alternative career with roadmaps.

🧠

AI Study ChatBot

24/7 AI assistant powered by HuggingFace Qwen model. Answers from Resource Hub data. Supports English and Hinglish. Login to save history.

🎓

Seniors Wall

LinkedIn-style platform for seniors to share their journey, achievements, company placements and tips for juniors.

🎮

SkillCheck AI

Dynamic MCQ generator that tests knowledge from Resource Hub materials or general tech subjects. Predicts skill level and identifies weak topics.

🤖 ML Models & Algorithms

How AI powers each module

📊 K-Means Clustering

Used in: Career Predictor

Groups students into 8 clusters based on their skills (Python, ML, SQL, Web, Mobile, Security, Cloud). Each cluster maps to a career path. Trained on 40 sample student profiles using StandardScaler normalization.

Evaluation: Silhouette Score for cluster quality

🔗 Apriori Algorithm

Used in: Career Predictor (skill suggestions)

Association rule mining finds patterns like "students who know Python and ML also benefit from learning Stats". Generates skill improvement suggestions with confidence scores.

Parameters: min_support=0.15, min_confidence=0.5

🧠 HuggingFace LLM (Qwen2.5-72B)

Used in: AI ChatBot, Exam Paper Generator, MCQ Generator

Qwen/Qwen2.5-72B-Instruct — free, permanent model via HuggingFace InferenceClient. Understands English and Hinglish. Used for conversational AI, exam paper generation based on study material, and MCQ generation.

📏 Rule-Based Career Refinement

Used in: Career Predictor

Post-processing layer on top of K-Means. Refines cluster prediction using student's specific tool selections (e.g., LangChain → LLM Engineer, Kotlin → Android Developer). Ensures accurate final prediction.

⚙️ How Each Module Works

Technical working of all 6 modules

📚 Resource Hub — How it works

Admin uploads study materials (PDF, Word, Images) via Admin Panel → Files saved to Cloudinary cloud storage → URL stored in SQLite database → Students filter by subject → Open material link. ChatBot also uses these resources to answer student questions.

📝 Exam Compass — How it works

Past Papers: Admin adds Google Drive links → Students browse by subject/year → Direct access. AI Generator: Student selects subject and marks → Flask reads resource content from Cloudinary URLs → HuggingFace AI generates paper following past paper patterns and resource topics → Download as text file.

🎯 Career Predictor — How it works

Student selects skills across 5 steps → Scores calculated (1-5) for 8 skill dimensions → Sent to Flask ML API (port 5001) → StandardScaler normalizes data → K-Means predicts cluster → Rule-based refinement fine-tunes prediction → Apriori rules suggest missing skills → Results shown with roadmap download link.

🧠 AI Study ChatBot — How it works

Guest mode: Chat works, history not saved. Login mode: History saved per conversation in SQLite. Each message: Flask reads all resources from DB → Fetches content from Cloudinary URLs → Sends to HuggingFace Qwen AI with resource context → AI answers based on study material → If topic not found, shows upload option.

🎓 Seniors Wall — How it works

Admin creates senior accounts → Senior logs in with username/password → Updates profile (company, role, bio, LinkedIn, GitHub) → Uploads profile photo to Cloudinary → Adds posts with images → Public wall shows all seniors with search/filter by name, company, batch year.

🎮 SkillCheck AI — How it works

Student logs in (same account as ChatBot) → Selects subject (Resource Hub subjects or General tech) → Flask reads resource content → HuggingFace AI generates unique MCQs based on actual material → Student answers → Score calculated → Level determined (Beginner/Intermediate/Advanced/Expert) → Weak topics identified → Attempt saved to history.
